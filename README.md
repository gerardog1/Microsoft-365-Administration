# Microsoft-365-Administration
A collection of Microsoft 365 administrative IT tasks that I simulated to get hands-on experience and documentation practice.

## Scenarios

| # | Scenario | Tools and concepts | Tested |
|---|----------|--------------------|--------|
| 1 | [New hire setup](tasks/01-new-hire-setup.md) | Microsoft 365 admin center, licenses, groups | ☑ |
| 2 | [Shared mailbox access](tasks/02-shared-mailbox-access.md) | Exchange Online shared mailboxes, approvals | ☑ |
| 3 | [MFA reset after a new phone](tasks/03-mfa-reset.md) | Entra admin center, Microsoft Authenticator, identity verification | ☑ |
| 4 | [Outlook closes at startup (add-in)](tasks/04-outlook-addin-startup-crash.md) | Outlook safe mode, COM add-ins | ☑ |
| 5 | [Offboarding](tasks/05-offboarding.md) | Blocking sign-in, shared mailbox conversion, license removal | ☑ |
