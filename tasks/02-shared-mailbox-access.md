# Scenario 2: Shared mailbox access

- [ ] Reproduced in a Microsoft 365 trial tenant

## Ticket

> "Hi, I started on the support team this week and I can't find the shared support inbox in my Outlook. My manager told me I'd have access. Can you add it?"

## First checks

1. **Get approval.** I'd look up the user's manager and use **Request approval** on the ticket. I would not add anyone to a shared mailbox just because they say their manager agreed.
2. Wait for the written approval before changing anything.

## Steps

1. Sign in to the Microsoft 365 admin center.
2. Click **Teams & groups**, then **Shared mailboxes**.
3. Click the **Support** mailbox. In the panel, under **Members**, click **Edit**, then **Add members**.
4. Search for the user, tick them, and click **Save**.
5. Reply on the ticket: give it about 15 minutes, then close Outlook completely and reopen it. If it is still not there after an hour, reply here and I will take another look.
6. Confirm with the user once the mailbox shows in Outlook.

## Ticket note

> User requested access to the Support shared mailbox. Approval received on the ticket from her manager. Added the user as a member in the Microsoft 365 admin center. User restarted Outlook and confirmed the mailbox appears. Follow-up: check with the user in two days to confirm she can send and read mail from it.

## Key takeaways

- Approval first, in writing.
- The mailbox does not show up instantly, so I give the user one clear time to wait and one clear time to come back.
- Shared mailboxes do not need their own license (under the size limit).
